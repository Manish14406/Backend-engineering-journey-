JWT -JASON web token 
It is a signed temporary pass assigned to the user after successfull autenfication. The client sents it with 
the future request rather then sending the password repeatedly.   
It contains the claims such as user id and expiry 

JWT ----3 parts
- Header -how is this token handled?
- Payload - what information does it carry 
- Signature - Has it been tampered with


1. Header
Contains information about the token, such as the signing algorithm.
Conceptually:

{
  "alg": "HS256",
  "typ": "JWT"
}

2. Payload
Contains claims about the user/token:
{
  "sub": "1",
  "email": "test@gmail.com",
  "exp": 1788000000
}

3. Signature
The signature is used to verify that the token was created by someone possessing the correct signing secret/key and that the signed contents haven't been changed.
Conceptually:
Header
   +
Payload
   +
Secret/Key
   ↓
Signature
